About & Methodology

Technical context for the digital twin: the 14-feature contract, derived calculations, and how explanations are produced.

What this product estimates

The application is a personal financial digital twin for next-month spending. It takes a current financial state, derives the remaining model features, and returns a CatBoost estimate. Scenario analysis and TreeSHAP explanations reuse the same contract.

Model and predictors

Predictions use a trained CatBoost regressor over a fixed 14-feature vector. Primary inputs are entered in Twin; derived features (current spending, three-month mean, three-month standard deviation with ddof=0) are computed by the backend and must not be overridden in a scenario.

Scenarios and explanations

A What-If run changes one allowed primary input, rebuilds derived features, and compares two model estimates. TreeSHAP attributions describe how features contribute to a single estimate. They do not prove that changing a real-world behaviour would produce the same difference.
